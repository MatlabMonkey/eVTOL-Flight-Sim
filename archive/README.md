# Archive

This folder holds scripts and assets that are no longer part of the active
`eVTOL_Simulation` workflow.

- `legacy_workflow/`: older trim, batch-trim, and scenario-run scripts that
  were replaced by the current `Init -> Trim -> Run` path.
- `debug_tools/`: one-off helper scripts that were useful during debugging but
  are not part of the day-to-day workflow.
- `decommissioned_avl/`: retired AVL-specific code and study artifacts.

The active workflow lives at the top level of `eVTOL_Simulation`.
