eVTOL_Simulation Quick Start

Fast commands for using the current folder workflow without reading the whole architecture doc.

Current active models: Trim_Plant for trim and Wrapper for runs.

1. Default Workflow

Init_EVTOL_Main
trimCase = ...
Trim_EVTOL_Main
Build_Controller_EVTOL_Cruise   % only if trim succeeded
runCase = ...
Run_EVTOL_Main

The run script uses Wrapper, not Plant.

3. Build The Controller

The controller build is for the cruise LQR path and expects a successful trim result first. 

Init_EVTOL_Main
trimCase = TrimCase_Cruise75();
Trim_EVTOL_Main
Build_Controller_EVTOL_Cruise

Since the exact cruise trim cases are still unresolved, expect the controller path to be in progress unless you have a validated cruise trim.

4. Run The Wrapper

Prep the wrapper without simulating

Init_EVTOL_Main
trimCase = TrimCase_Hover();
Trim_EVTOL_Main
runCase = RunCase_PrepOnly();
Run_EVTOL_Main

Attempt a wrapper simulation

Init_EVTOL_Main
trimCase = TrimCase_Hover();
Trim_EVTOL_Main
runCase = RunCase_OpenLoopMainAttempt();
Run_EVTOL_Main

Main outputs left in the workspace: runSpec, runContext, runResult, and simOut.

5. Plot Outputs

The plotting helper expects a workspace variable named out. After a run, copy: 

out = simOut;

Then use:

plot_evtol_workspace_outputs
plot_evtol_workspace_outputs('important')
plot_evtol_workspace_outputs('all')

6. Make A Video

The simplest usage after a wrapper run is: 

make_evtol_video('sim_out', simOut)

Or, if you want to use the default workspace variable name: 

out = simOut;
make_evtol_video('sim_out_var', 'out')

Videos are written to workspace_plots/ by default.

8. Files To Remember

File What it is for

Trim_EVTOL_Main.m Run one trim case
Build_Controller_EVTOL_Cruise.m Build the cruise LQR controller
Run_EVTOL_Main.m Prepare and optionally simulate the wrapper
plot_evtol_workspace_outputs.m Plot wrapper output signals
make_evtol_video.m Render an MP4 from wrapper outputs
cases/trim/TrimCase_Hover.m Current known-good trim case
