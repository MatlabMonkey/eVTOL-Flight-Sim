# Archived Controller Experiments

This folder holds one-off controller demos, route experiments, jump-gap
work, and legacy prep/build scripts that are no longer part of the active
workflow.

Active controller-side files now live in:

- `controllers/builders/`
- `controllers/presets/`
- `planning/`
- `plotting/`

If an archived script is still needed, copy its settings into the active
builder/preset/planner chain instead of restoring another top-level prep
script in the root.
